Your 8085 assembly code
You only type the code. The website turns instructions into machine bytes, stores them in PROGRAM memory, and shows the CPU step by step. For LDA 2050H, 2050H is an ADDRESS; the DATA is Memory[2050H]. You can also write DATA 2050H, A8H to place data directly in memory.
Supported 8085 instructions & limits
MOV, MVI, LXI, LDA, STA, LHLD, SHLD, XCHG, ADD, ADC, ADI, SUB, SBB, SUI, CMP, CPI, INR, DCR, INX, DCX, DAD, CMA, ORA, XRA, JMP, JC, JNC, JZ, JNZ, JM, JP, HLT, NOP, STC, CMC, plus labels and DATA. This is a learning emulator for the exercises, not a complete 8085 implementation. Programs with unsupported instructions show an error rather than faking execution. Max 600 executed instructions.

Addresses are 16-bit. Each memory cell holds exactly one 8-bit byte. Program bytes and data bytes are shown together; read/write actions are highlighted.
How to teach with this: Show the student the left column first. The assembled bytes appear below the code. Then follow the highlighted instruction on the right, watch its operand travel to the CPU, the ALU compute, the flags update, and the result get stored back in memory. Nothing changes randomly: the animation follows actual simulated instructions.
